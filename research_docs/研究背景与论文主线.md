# 研究背景与论文主线

> 文档性质：本项目的稳定背景与长期研究主线。
> 适用范围：学位论文、两篇小论文、实蝇目标检测、多目标跟踪、野外长视频分类计数和树莓派部署。
> 使用规则：新会话处理本项目前应先阅读本文档，再阅读 `当前进展与下一步.md`。若本文档与用户当前指令冲突，以用户当前指令为准。

## 1. 研究对象与应用背景

本项目面向植物检疫和农业害虫智能监测，以两种形态高度相似、均可被甲基丁香酚诱集的检疫性实蝇为对象：

- 橘小实蝇 *Bactrocera dorsalis* (Hendel)；
- 番石榴果实蝇 *Bactrocera correcta* (Bezzi)。

最终应用目标是在真实诱捕场景中实现按物种区分的长时程自动监测，形成“检测—跟踪—分类计数—边缘运行”闭环。实际难点不只是单帧识别，还包括近缘种类间特征相似、小目标、运动模糊、复杂诱捕器背景、快速飞行、突变运动、遮挡、轨迹碎片化和长时程计数误差累积。

## 2. 两篇小论文的定位

### 2.1 第一篇论文：FlyYOLO-SORT

第一篇论文已完成，稿件为 `paper/manuscript_revised_unmarked.docx`。

#### 研究场景

- 实验室受控条件；
- 培养皿和 A4 纸白色背景；
- 近距离、高对比度、高分辨率成像；
- 视频中包含快速飞行、大位移、侧跳、遮挡和个体交汇等复杂运动。

#### 核心目标

1. 验证机器视觉能否在受控条件下精细区分两种形态相似的实蝇；
2. 验证跟踪算法能否在快速飞行、大位移、遮挡和运动突变下保持身份连续。

#### 主要方法

- 检测端 FlyYOLO：StarNet 轻量骨干、BSDFM 深浅特征融合、LQE-detect 定位质量评分；
- 跟踪端 FlyYOLO-SORT：DBCF 轴对齐框/旋转框互补融合、SNMS 抑制重复多类预测、AEM 角度感知欧氏匹配。

#### 评价边界

- 检测使用 Precision、Recall、mAP、参数量、FLOPs 和 FPS；
- 跟踪使用 HOTA、MOTA、MOTP、IDF1 和 IDSW 等标准 MOT 指标；
- 论文定位是受控条件下的“精细识别与复杂运动跟踪能力验证”；
- FlyYOLO 的检测结构针对理想高分辨率场景设计，不预设其为大论文或第二篇论文在真实诱捕场景中的最终检测方案。

### 2.2 第二篇论文：真实诱捕长视频分类计数

第二篇论文处于研究和实验设计阶段。

#### 研究场景

- 真实诱捕器场景；
- 复杂背景、光照变化、小目标、黏连遮挡和运动模糊；
- 长时程视频，逐帧身份标注成本高；
- 检测与跟踪结果作为分类计数研究的冻结输入条件。

#### 核心目标

1. 将经实验室标准 MOT 验证的跟踪方法应用到真实长视频，评价其对最终逐物种计数的下游价值；
2. 分析初始占用、轨迹碎片、边界徘徊和类别抖动造成的结构性计数误差；
3. 构建并验证能够减少上述误差的长时程分类计数方法。

#### 研究定位

第二篇论文不应写成“把第一篇模型搬到树莓派，再加一条计数线”，也不把跨场景检测、标准跟踪、分类计数和边缘部署全部并列为论文贡献。其主要科学问题是：当逐帧感知已经较为可靠时，为什么真实诱捕长视频的分类计数仍会发生结构性错误，以及如何减少这些错误。

#### 与学位论文的范围边界

> 第二篇论文聚焦真实诱捕长视频分类计数，负责回答“最终能不能数准”；学位论文则进一步整合跨场景检测、标准跟踪、真实分类计数与树莓派部署，完整回答“看得见、跟得住、数得准、跑得动”。

## 3. 两篇论文的承接关系

两篇论文通过研究对象、应用需求和证据链串联，不强求复用完全相同的检测网络模块。

### 3.1 实验室数据证明跟踪能力

实验室视频可以完成逐帧 ID 标注，因此用于严格回答：

> 所提跟踪方法是否真正改善了实蝇复杂运动下的身份关联？

可以评价 HOTA、IDF1、MOTA、IDSW、轨迹碎片数以及快速飞行、遮挡、侧跳等子场景的性能。

### 3.2 真实长视频证明下游应用价值

真实长视频不强求制作完整逐帧 MOT ID 真值，但必须拥有逐视频、逐物种人工计数真值。它用于严格回答：

> 在相同检测结果和相同计数规则下，哪一种跟踪器能够带来更准确的最终分类计数？

可以评价 `correcta MAE`、`dorsalis MAE`、Class-MAE、Total-MAE、完全正确视频比例、负计数比例和处理 FPS。

### 3.3 允许与禁止的结论

允许的表述：

> 本方法在实验室标准 MOT 数据上改善了复杂运动条件下的身份保持性能，同时在真实诱捕长视频上获得了更低的分类计数误差。

禁止的表述：

- 不能仅根据野外计数结果声称跟踪器在野外数据上的 HOTA、IDF1 或 MOTA 更高；
- 没有逐帧 ID 真值时，野外实验只能表明下游计数性能，不能代替标准 MOT 评测；
- 不能将服务器 CPU 或 GPU 的推理速度当作树莓派实测速度。

## 4. 学位论文的总体时间线和逻辑

学位论文采用“真实需求提出问题—实验室可控数据验证机制—真实长视频验证应用价值”的叙事逻辑。

1. 首先获得真实诱捕场景长视频，从真实长时程监测需求中提出跨场景感知、身份关联和分类计数问题；
2. 构建同时面向实验室受控场景和真实诱捕场景的统一轻量化目标检测方法，解决“两个场景都能不能看见”；
3. 由于真实长视频完整逐帧 ID 标注成本过高，主动设计可控实验室运动场景，复现真实诱捕中具有代表性的快速飞行、大位移、运动状态切换、遮挡和个体交汇，建立可逐帧标注的标准 MOT 数据集；
4. 在实验室 MOT 数据上研究跟踪方法，使用标准 MOT 指标证明身份关联机制有效，解决“飞行过程中能不能跟住”；
5. 将验证后的跟踪方法应用于真实长视频，在固定检测结果和计数规则的条件下，通过最终分类计数误差评价其实际价值，解决“长时间运行最终能不能数准”；
6. 检测后端、输入尺寸、跟踪和计数优化以及树莓派长时间稳定性实验，均围绕真实长时程监测主线展开，不再单独形成与主线并列的研究目标。

叙事中不使用“苦于无法标注，无奈只能做实验室实验”的弱表述，而应写成：

> 真实场景提出应用问题，实验室可控数据提供可重复、可逐帧标注的标准跟踪验证条件，真实长视频负责最终应用验证。

## 5. 学位论文的三个研究目标

### 目标一：受控—真实场景的稳定目标检测

构建在实验室受控场景和真实诱捕场景中均保持较高精度的轻量化实蝇检测模型，解决小目标特征丢失、近缘种相似、复杂背景干扰和运动模糊问题，并考虑树莓派计算约束。

检测模型不只按单一数据集最高 mAP 选择，应同时比较受控集性能、真实集性能、最差域性能、参数量、FLOPs 和树莓派 FPS。

### 目标二：复杂飞行条件下的多目标跟踪

利用可逐帧标注的实验室视频，研究快速飞行、大位移、运动状态突变、遮挡和相似个体交汇条件下的身份关联方法，使用标准 MOT 指标验证算法机制。

### 目标三：真实长视频分类计数与边缘运行

将检测和跟踪方法应用到真实长视频，通过逐视频、逐物种人工计数真值评价不同跟踪器的下游效果，并在树莓派上验证准确性、实时性和长时间稳定性。

## 6. 建议的学位论文章节

### 第1章 绪论

总问题：

> 如何在受控与真实诱捕场景下实现近缘检疫实蝇的稳定检测，并利用实验室可控数据解决复杂飞行运动下的身份关联问题，进而在缺少逐帧身份标注的真实长视频中实现准确、实时的分类计数？

### 第2章 数据采集平台与跨场景数据集

统一介绍受控图像检测数据、真实图像检测数据、实验室 MOT 视频及逐帧 ID 标注、真实长视频及逐物种计数真值、树莓派部署平台、数据划分和指标体系。

### 第3章 受控—真实场景下的统一目标检测

建议实验至少包括：

- 分别训练、分别测试；
- 混合训练、分域测试；
- 受控训练 → 真实测试；
- 受控预训练 → 真实微调；
- 统一模型与两个域专用模型对比；
- 受控域 mAP、真实域 mAP、最差域性能、复杂度和树莓派性能联合选型。

领域差异直接融入统一检测模型设计和实验，不单独设置与三个研究目标并列的“领域偏移”章。

### 第4章 复杂飞行模式下的实蝇多目标跟踪

使用具有逐帧 ID 标注的实验室可控 MOT 数据，研究快速飞行、爬行—飞行状态切换、侧向跳跃、遮挡和相似个体交汇下的身份关联，以 HOTA、IDF1 和 IDSW 为核心指标，并承接第一篇论文的 DBCF、AEM 等跟踪思想。

### 第5章 真实诱捕长视频下的分类计数

固定同一检测模型、同一份逐帧检测结果、同一套计数规则和同一批真实视频，仅替换跟踪器，使用最终 Class-MAE 等指标检验实验室跟踪性能改善是否能转化为真实计数收益。

### 第6章 树莓派端到端部署与系统验证

比较不同推理后端、输入尺寸和加速策略，报告 FPS、延迟、内存、功耗、全链路精度与长时间运行稳定性。若工作量不足以形成独立研究章，可并入第5章。

## 7. 数据集之间的关系

不要强求所有研究使用同一数据集。正确设计是“同一生物学对象和监测目标，统一数据谱系，任务专用子集”。

| 数据子集 | 主要内容 | 标注 | 主要用途 |
|---|---|---|---|
| 受控检测数据 | 白底、高分辨率实蝇图像 | AABB/OBB、物种 | 受控检测与第一篇论文 |
| 真实检测数据 | 诱捕器复杂背景图像 | 检测框、物种 | 跨场景统一检测 |
| 实验室 MOT 数据 | 可控复杂运动短视频 | 逐帧框、物种、轨迹 ID | 标准 MOT 评测 |
| 真实计数数据 | 诱捕场景长视频 | 逐视频、逐物种数量；可选事件标注 | 下游分类计数 |
| 边缘流数据 | 树莓派连续采集和运行流 | 性能日志、故障和采样真值 | 边缘部署与长时间稳定性 |

如从真实计数视频中抽帧建立检测数据，必须以完整视频、采集日期或采集批次为单位划分训练、验证和测试集，不得将同一视频的不同帧分散到不同子集。数据增强只用于训练集。

## 8. 实验室与真实场景的运动关系

不声称两个场景中的实蝇具有“一模一样”的运动分布。正确表述是：

> 实验室可控场景复现并覆盖了真实诱捕场景中与多目标关联密切相关的代表性运动挑战。

建议通过抽样片段对比以下变量，证明实验室数据对真实关联难点的覆盖性：

- 相邻帧中心位移及按身体尺度归一化的位移；
- 速度、加速度、转向角和姿态角变化；
- 遮挡发生率、目标密度、连续丢失帧数；
- 静止、爬行、快速飞行和状态切换的比例；
- 运动模糊程度。

无需证明两个分布完全相同，但需要证明实验室数据包含足够的高难度关联事件，并由真实长视频计数实验补充外部应用验证。

## 9. 必须遵守的实验原则

### 9.1 跟踪器的真实计数对比

为将计数收益归因于跟踪器，必须固定：

- 同一目标检测模型和权重；
- 同一份逐帧检测结果；
- 同一批视频和字节内容；
- 同一计数区域和坐标变换；
- 同一进入/退出事件规则；
- 同一初始占用处理方式；
- 同一类别投票和类别锁定方式；
- 每个视频独立初始化；
- 同一最终计数量定义。

实验只替换跟踪算法及其必要内部参数。如某方法必须替换检测器才能运行，应归入端到端系统对比，不得与“仅替换跟踪器”的受控实验混合。

当前计划比较的 8 个候选为 SORT、ByteTrack、OC-SORT、SF-SORT、FastTracker、BoostTrack、HybridSORT 和 BoT-SORT。根目录检测入口不绑定任何候选跟踪器；若 ByteTrack 最终最优，采用 `tracking_model_benchmark/02_bytetrack/` 中的正式候选实现。

工程上采用“原视频 → 统一全帧逐帧检测数值缓存 → 逐帧轨迹数值缓存 → 计数结果”的分层重放。首轮 8 算法 baseline 不启用 ROI，ROI 留作后续计数优化变量。8 个候选统一消费 `Nx6 [xyxy,confidence,class_id]`，统一输出 `Nx8 [xyxy,track_id,confidence,class_id,detection_index]`，计数器不依赖具体跟踪器。跟踪优化复用同一检测缓存，计数优化复用同一轨迹缓存；任何上游条件变化都必须使对应下游缓存失效。具体格式和校验以 `检测-跟踪-计数数值缓存与重放协议.md` 为准。

### 9.2 计数真值与计数量定义

下列三种量不得混用：

1. 累计进入数 `N_enter`；
2. 净跨界量 `N_enter - N_exit`；
3. 末帧区域占用数 `N_start + N_enter - N_exit`。

当前 6 个真实逻辑长视频的人工真值已由用户确认为“全部片段拍摄结束后的瓶内逐物种最终占用数”。算法评价必须采用第 3 种定义；若代码从 0 开始累计有符号净跨界量，必须先核验对应逻辑长视频的 `N_start=0`，否则应显式登记并加入初始占用数。

正式实验前必须人工核验视频文件名中数字的真实含义、两种实蝇的顺序与 class ID 对应关系。未核验的文件名数字不能直接用作论文真值。

### 9.3 数据划分与调参

- 按完整视频、采集批次或采集日期划分数据；
- 开发集用于检查链路，验证集用于调参和选型，测试集在方法冻结后只运行最终评价；
- 禁止根据测试集结果反复调整跟踪或计数参数；
- 数据增强只应用于训练集。

## 10. 一句话主线

> 首先构建同时适应实验室受控场景和真实诱捕场景的实蝇检测方法；随后利用具备逐帧身份标注的实验室复杂飞行视频，研究快速运动与遮挡条件下的多目标关联；最后将检测与跟踪方法应用于难以获得完整 MOT 标注的真实长视频，通过最终分类计数误差验证跟踪器的实际价值，并在树莓派上完成端到端运行。

对应三个直接问题：

> 两个场景都能不能看见？
> 飞行过程中能不能跟住？
> 长时间运行最终能不能数准？
