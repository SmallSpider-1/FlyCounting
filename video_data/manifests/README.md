# 真实长视频计数数据清单

## 数据单元

`video_data/` 当前包含 6 个逻辑长视频、25 个物理 MP4 片段。正式计数和评价以逻辑长视频为单位：同一目录内的片段按 `segments.csv` 的 `segment_index` 处理，片段边界重置跟踪器，但有符号区域计数在同一逻辑长视频内连续累计。

- `long_videos.csv`：6 个逻辑长视频的目录、规模、聚合规则和目录级真值摘要；
- `segments.csv`：25 个视频片段的规范路径、重命名前路径、确定性处理顺序和媒体元数据；
- `ground_truth_v1.csv`：按逻辑长视频和物种记录的人工计数真值；
- `diagnostic_subgroups_v1.csv`：从原目录名和原片段名保留下来的子组真值，只用于片段/子组误差诊断；
- `splits_v1.csv`：开发/验证/测试划分占位表，当前全部为 `unassigned`，不得据此声称正式划分已冻结。

## 真值和顺序边界

- 目录名和 `ground_truth_v1.csv` 中的物种顺序均已显式写为 `dorsalis`、`correcta`，不依赖模型内部 class ID；
- 用户已确认目录级人工真值表示所有片段拍摄结束后瓶内的最终逐物种数量，即最终瓶内占用数；算法预测从 0 开始累计进入 `+1`、离开 `-1`，不再把负数截断为 0，负预测保留为算法误差；
- `diagnostic_subgroups_v1.csv` 保留了重组前的 17、25、219、11/8 及带物种数字片段等子组真值；它们可用于诊断过计数/漏计数抵消，但正式主指标仍以 6 个逻辑长视频为单位；
- `segment_index` 是本次预处理采用的确定性执行顺序。对无法从原文件名恢复真实采集时间线的片段，它不等同于已经核实的拍摄先后。

## 文件处理说明

2026-07-25 的预处理只在同一文件系统内重命名目录和文件，没有转码、裁剪或修改视频字节。重命名前后 25 个 MP4 的设备号、inode 和字节大小全部一致。媒体全量探测结果为 25/25 可读取，分辨率均为 2304×1296，视频帧率约为 56 FPS。
