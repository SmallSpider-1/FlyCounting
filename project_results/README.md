# 项目结果目录

本目录统一存放实蝇检测、跟踪与分类计数相关的工程结果和诊断证据，不存放原始视频、检测数据集或模型权重。

| 子目录 | 内容 | 当前证据性质 |
|---|---|---|
| `result_boxmot_one_class_219_yolo26n/` | 一类长视频的历史 BoxMOT 计数 CSV | 早期工程结果 |
| `result_boxmot_two_class_61_118_yolo8n/` | 两类长视频的历史 BoxMOT 计数 CSV | 早期工程结果 |
| `result_counting_cache/` | 检测与 ByteTrack 轨迹缓存及计数重放输出 | 可再生成的工程缓存 |
| `result_two_class_79_27_individual/` | 负计数、born-inside、轨迹碎片和边界事件诊断 | 当前研究文档引用的诊断证据 |

结果 CSV 和配置文件中记录的旧绝对路径是实验运行时的历史元数据，迁移目录时不改写。它们可能不再对应当前文件位置，但应保留以免改变实验溯源记录。

现有结果只支持程序链路验证和误差诊断；除非研究状态文档另有明确记录，不应将其表述为已冻结的正式论文结果。
